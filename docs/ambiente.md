Ambiente de desenvolvimento



Sistema operacional



Windows.



Ferramentas utilizadas



Python: versão 3.15.1, verificada durante o desenvolvimento.



Git: versão 2.56.0.



Visual Studio Code: editor utilizado para escrever e organizar o código.



Organização do ambiente Python



O projeto utiliza um ambiente virtual chamado .venv, destinado a manter as dependências do Python isoladas do ambiente global.



Como executar os exercícios



Na raiz do repositório, execute um exercício com o comando:



python aprendizado\\semana1\\ex01.py



Para executar os demais exercícios, substitua ex01.py pelo nome do arquivo desejado, de ex02.py até ex08.py.



Arquivos ignorados pelo Git



O arquivo .gitignore está configurado para ignorar o ambiente virtual .venv/, arquivos temporários do Python, a pasta saida/, a pasta dados/massas/ e arquivos com extensão .db.



Objetivo



Manter documentadas as ferramentas e os procedimentos básicos necessários para desenvolver e executar os exercícios do projeto.

Validador e Importador de Planilhas de Cursos FIC



Projeto desenvolvido no contexto do IFRN para estudar e construir uma solução que ajude a validar e importar planilhas de cursos de Formação Inicial e Continuada (FIC).



Aprendizado — Semana 1



Esta etapa reúne oito exercícios introdutórios de Python:



Apresentação de um curso.



Cálculo de semanas de curso.



Validação de turnos.



Verificação da quantidade de vagas.



Cálculo de horas acumuladas.



Organização de uma lista de cursos.



Cálculo de maior, menor, soma e média de cargas horárias.



Contagem de turnos válidos e inválidos.



Como executar



É necessário ter Python instalado. Na raiz do projeto, execute, por exemplo:



python aprendizado/semana1/ex01.py



Os demais exercícios estão nos arquivos ex02.py até ex08.py, na mesma pasta.



Estrutura



aprendizado/semana1/: exercícios de Python.



docs/: documentação do projeto.



docs/evidencias/: evidências da atividade.



.gitignore: arquivos e pastas ignorados pelo Git.



Objetivo



Desenvolver conhecimentos de programação e preparar a base para uma futura ferramenta de validação e importação de planilhas de cursos FIC.
